# SOM

**IBM SOM (System Object Model)** implementation of the CORBA POS example.

Includes SOM bindings, IDL artifacts, and a top-level `MAKEFILE` for AIX and related platforms (`AIXFILES` lists platform-specific pieces).

Build on a system with the SOM runtime and compilers available when this example was published. See the main [**CORBA** README](../README.md) and IBM SOM documentation for bind and run steps.
