# OBJBRKR

**Object Broker (OBJBRKR)** implementation of the CORBA POS example.

Sources and Makefiles for running the multi-server POS demo on the Object Broker ORB. Refer to [`OBB-READ.TXT`](OBB-READ.TXT) and other local notes for vendor-specific setup.

See the main [**CORBA** README](../README.md) for the shared IDL layout and Unix tarball option.
