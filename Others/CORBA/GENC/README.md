# GENC

**Generic C** porting layer for the CORBA POS example. Provides C sources and Makefiles used as a template when bringing the POS demo to a C-based ORB environment.

Typical subcomponents: central server, store, POS terminal, and PNS (product naming)—matching the book’s multi-process example.

See the main [**CORBA** README](../README.md). Build after generating stubs from the shared [`IDL/`](../IDL/) definitions with your ORB’s tools.
