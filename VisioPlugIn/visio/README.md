# visio

**Visio API** support and wrappers used by the NetInfo/VisioPlugIn DLL: type definitions (`Visio.h`, `V41objs.h`), registration (`Ivisreg.cpp`/`.h`), automation proxies (`Ivisprox.h`, `Ovisprox.h`), add-in entry (`Vaddon.cpp`, `Vdllmain.c`), and helpers. Enables the plug-in to talk to Microsoft Visio. Build is part of the parent **VisioPlugIn** project.
