# XPropertiesWnd

**ActiveX control** (MFC): a properties-window style control. ControlWizard-generated skeleton with one control, property page, and ODL type library. Use as a starting point for a custom property-grid or properties-panel control in a container (e.g. VB, MFC app).

## Build and run

- Visual C++: `XPropertiesWnd.mak` / `.dsp`. Produces an OCX.
- Register the OCX (e.g. `regsvr32`) and insert the control into a container that supports ActiveX.
