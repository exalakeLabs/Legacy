# Legacy

A collection of legacy C/C++ and Windows projects: demos, tests, and sample code from the 1990s–2000s. Includes concurrency demos, COM/ActiveX, CORBA, OpenGL, Win32 APIs (pipes, shared memory, threads, timers), data structures, and build tooling.

## Contents overview

| Area | Folders |
|------|--------|
| **Concurrency & processes** | `philsophe`, `Proc&Thread`, `ThreadTest`, `CreatePipe`, `OldProcWrap` |
| **COM / ActiveX** | `COMObject`, `COMClient`, `CLSIDTest`, `OCXREG`, `DCOM`, `dllDialog`, `ActiveListBox`, `ActiveListBoxTest`, `XPropertiesWnd`, `XFloorWnd`, `RemoteShell OCX` |
| **CORBA** | `CORBA` (POS example from “CORBA Fundamentals and Programming”) |
| **Graphics / OpenGL** | `OpenGLSurefire`, `qknots`, `texturemapping`, `RGBtoGLByte`, `C++Builder/OpenGLPerspective`, `C++Builder/BitmapTest` |
| **Win32 / system** | `Timer`, `mapfile`, `shmemop`, `shmemcr`, `winsock`, `winCE Winsock`, `Dialog Wnd` |
| **Data structures & math** | `Bin Tree`, `LISTS`, `QSort`, `MATH`, `Matrix` |
| **C++Builder / Delphi** | `C++Builder` (components, DB, OpenGL), `DLLTest`, `dvcrpage` |
| **Other** | `ExceptionTest`, `fstreamTest`, `surlecul`, `VisioPlugIn`, `Wolf3DSrc`, `src/way-back` |

See each project’s `README.md` for what it does and how to build or run it.
