# XFloorWnd

**ActiveX control** (MFC): floor-plan or floor-window style control. ControlWizard-generated skeleton with one control, property page (`XFloorWndPpg`), and ODL. Use as a starting point for a custom “floor window” or similar UI control in an ActiveX container.

## Build and run

- Visual C++: `XFloorWnd.mak` / project files. Builds an OCX.
- Register the OCX and embed in a container (e.g. VB, MFC dialog).
