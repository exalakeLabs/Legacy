# texturemapping

**OpenGL** demos and samples focused on **texture mapping** and related rendering. Under `Package` are MFC/OpenGL dialog apps (e.g. Antialiasing, Gouraud, Lighting, TextureMapping, Texturetransparency, TextureLighting) that combine a dialog UI with an OpenGL view. Each subfolder typically has a ReadMe.txt and DialogGL-style project. Use for learning or porting texture/lighting techniques.

## Structure

- **Package/** — Per-topic demos (Antialiasing, Gouraud, Lighting, TextureMapping, etc.), each with sources and ReadMe.
- **Bin/** / **Web/** — Build output or web-related assets if present.

Build each demo with Visual C++ (open the project in the corresponding Package subfolder).
