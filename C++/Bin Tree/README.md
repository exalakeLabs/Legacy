# Bin Tree

**Template** header `Bintree.h`: generic binary tree with `TreeNode` (links: Less, More, Parent; data) and associated tree logic. Copyright 1993–1995 Scott Robert Ladd. Use as an include-only library for binary trees in C++.

## Usage

Include `Bintree.h` in your project; instantiate the template with your data type. No separate build step; compile your own code that includes it.
