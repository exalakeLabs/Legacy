# RGBtoGLByte

**OpenGL** demo “maiden” (Nate Robins, 1997): torus and spheres with colors, using `sgi.h` and GLUT. Name suggests RGB-to-OpenGL-byte or similar conversion used for color handling. Builds with Visual C++ (`maiden.dsp`/`maiden.mak`) and requires OpenGL and GLUT.

## Build and run

Build the maiden project (link OpenGL/GLUT). Run the executable to view the demo.
