# LISTS

**Template** container headers: `Contx.h`/`Contx.cpp` (context/allocator) and `Deque.h` (double-ended queue, `DequeDynamic`). Copyright 1995 Scott Robert Ladd. Use as include (and optional .cpp) for deque and related list structures in C++.

## Usage

Include the headers in your project; link `Contx.cpp` if your build uses the context implementation. No standalone executable; this is a library of data structures.
