# MATH

Minimal **square root** demo: implements `ma_sqrt(double x)` via Newton-style iteration (tolerance 1e-7) and a small `main()` that reads a number and prints its square root. Uses Borland-style `classlib\dlistimp.h` and `iostream.h`/`math.h`. Educational example of a hand-written sqrt.

## Build and run

Compile `sqrt.cpp` with a C++ compiler that provides the referenced headers (Borland C++ or adjust includes). Run and enter a number when prompted.
