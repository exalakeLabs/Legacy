# dllDialog

MFC **regular DLL** generated by AppWizard. Demonstrates the basics of building a Windows DLL with MFC (e.g. `CDllDialogApp`). Can be extended to export dialogs or other UI/helpers for use by an EXE or other DLLs.

## Build and run

- Visual C++: `dllDialog.dsp`. Build the DLL.
- Use the DLL from an application that loads it and calls its exported functions or uses its resources.
