# Matrix

**Template matrix** class and test app. `matrix.h`/`matrix.cpp` define `Matrix<T>` with indexing, +/−/*/÷ by scalar, matrix multiply, and row/column access. `TESTMATRIX.cpp` exercises the class. Visual C++ project: `TESTMATRIX.dsp`.

## Build and run

Open `TESTMATRIX.dsp`, build, and run the test executable.
