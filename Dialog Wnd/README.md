# Dialog Wnd

**Diagnostic and exception** helpers for Windows: `DiagOutWin` in `diagwin.cpp`/`diagwin.h` displays messages in a message box with a level (e.g. DIAG_FATAL, DIAG_ERROR, DIAG_WARNING, DIAG_MSG). Fatal stops the program; Error offers “Yes” (terminate) / “No” (continue). Copyright 1995 Scott Robert Ladd. Use as a small library for user-visible diagnostics.
