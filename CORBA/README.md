# CORBA

CORBA **POS (Point of Sale) example** code from the book *CORBA Fundamentals and Programming* (Jon Siegel et al.). Contains implementations for multiple ORBs (e.g. NEO, ORBPLUS, ORBIX, EXPERSFT, SOM, etc.), plus generic C/C++ and IDL. Used for teaching and porting the example across ORB vendors.

## Contents

- **IDL** — Standard IDL for the example.
- **ORB-specific dirs** (e.g. NEO, ORBPLUS, ORBIX, EXPERSFT, SOM, DAIS, GENC, DST, GENCPP, OBJBRKR) — Implementation and makefiles for each ORB.
- **TARFILES** — Tarballs for Unix; use these to get the correct long filenames and structure.

See `README.TXT` in this folder for copyright, permissions, and per-ORB build/run instructions. Build and run steps depend on which ORB you use.
