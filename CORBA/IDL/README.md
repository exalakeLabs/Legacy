# IDL

**OMG IDL** sources for the CORBA POS example: `POS.IDL`, `STORE.IDL`, `PNS.IDL`, `CENTRAL.IDL`. Shared by the ORB-specific implementations in the parent directory. Build with the Makefile to generate stubs/skeletons for your ORB; see the main **CORBA** README and each ORB folder for compile and run instructions.
