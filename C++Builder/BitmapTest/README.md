# BitmapTest

C++Builder **VCL bitmap** demo (`Project1.bpr`). Creates a 64×64 compatible bitmap and memory DC, then fills it with random-colored pixels on a timer-driven button click—exercising `CreateCompatibleBitmap`, `CreateCompatibleDC`, `SelectObject`, and `SetPixel` from a form.

## Build and run

- Open `Project1.bpr` in **C++Builder 1.x–3.x** (or compatible).
- Build and run; click the form button to start the pixel fill animation.

See the parent [**C++Builder** README](../README.md) for toolchain notes.
