# C++Builder

**Borland C++Builder** projects: components, database connectivity, OpenGL, and bitmaps. Mix of VCL forms and component packages for Windows.

## Subprojects

| Folder | Description |
|--------|-------------|
| **BCBComponent-NTServices** | NT-specific components (TNTService, TNTEventLog, TNTUserMan, TNTShare, TNTFileSecurity, TNTRegSecurity) for Delphi 2–4 and C++Builder 1/3. Install via NTSet.bpg (Delphi 4) or the appropriate package. |
| **BitmapTest** | Bitmap handling demo. |
| **C++BuilderComponent** | Custom C++Builder component(s); includes OpenGLControl. |
| **databaseConnection** | Database connection demo (Unit2 form). |
| **DatabaseConnectionTest** | App that uses both a main form and the databaseConnection form (Unit2). |
| **OpenGLPerspective** | OpenGL perspective demo (VCL form). |

See each subfolder for project files (`.bpr`, `.bpg`, `.dpk`) and any local readme. Build with C++Builder 1.x–3.x or compatible IDE.
