# OpenGLControl

Core **VCL OpenGL control** (`OpenGLControl.cpp`/`.h`): wraps Windows OpenGL context creation and basic drawing hooks for use on C++Builder forms.

Part of the [**C++BuilderComponent**](../README.md) package. Install the parent package into the IDE before dropping this control on a form.

Used as the foundation for **TOpenGL** and **TOpenGLPanel** variants in sibling folders.
