# BCBComponent-NTServices

NT-specific VCL components for **Delphi 2/3/4** and **C++Builder 1/3**: TNTService, TNTEventLog, TNTUserMan, TNTShare, TNTFileSecurity, TNTRegSecurity. Install the package (e.g. NT.DPL, NT.bpl, or NTSet.bpg) then use the demos in the examples folder. See `readme.txt` in this folder for per-version install and path instructions.
