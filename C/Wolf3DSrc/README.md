# Wolf3DSrc

Source related to the **Wolfenstein 3D**–era id Software engine. C sources (`WL_*.C`, `WOLFHACK.C`, etc.) and x86 assembly (`C0.ASM`, `ID_*.ASM`) targeting **Borland C++ 3.0/3.1**.

## Build notes

From the original [`README/README.TXT`](README/README.TXT):

> This version will compile under BORLAND C++ 3.0/3.1 and compiled perfectly before it was uploaded.

Modern toolchains will not build this tree without substantial porting (16-bit assumptions, Borland inline assembly, DOS/Windows memory models).
