# surlecul

**IOCCC-style obfuscated C** program (playful name reversing “le cul sur”). Single recursive `main()` that produces output when run; no practical purpose beyond demonstrating extreme code obfuscation.

## Build and run

- Visual C++: open `surlecul.dsp`, build, run the console executable.
- Any C compiler: compile `surlecul.c` (or the main source file in this folder) and execute.

Pure curiosity—useful as a conversation piece or compiler torture test, not as library code.
